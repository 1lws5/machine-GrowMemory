# 传送带分拣控制系统 — 器件选型思路

> 本文讲清楚"为什么这么选"——不是给结论，而是给一套可复用的选型方法。
> 选型结论见《thesis-BOM物料清单.md》。

## 一、选型的核心观念

### 1.1 纠正一个常见误区

很多人以为选型是"性价比和需求之间找平衡"。这个说法不准确。

**正确顺序是：先满足需求，再谈性价比。** 性价比是最后一步，不是和需求并列的砝码。

> 选型 = 用"硬约束"一票否决掉不合格的，然后在剩下的合格品里挑总成本最低的。

"性价比"的完整含义是 **"满足需求前提下的最低成本"**，不是"越便宜越好"。选型翻车最常见的原因，就是把性价比当成"挑最便宜的"，结果选了便宜但干不了活的东西。

### 1.2 三步选型法（可复用到任何器件）

| 步骤 | 动作 | 说明 |
|------|------|------|
| 第 1 步 | 写需求清单 | 这器件必须完成哪几件事 |
| 第 2 步 | 翻译成硬约束 | 做不到就一票否决的条件 |
| 第 3 步 | 合格品里按软指标排序 | 这时才轮到价格/货期/售后/生态 |

**关键：硬约束是"及格线"，软指标是"排名分"。先及格，再排名。**

## 二、PLC 选型（为什么推汇川，不是信捷）

| 步骤 | 内容 |
|------|------|
| 需求 | 跑 ST 程序；至少 6 输入 + 6 输出；跑 Modbus TCP |
| 硬约束 | ① 支持 IEC 61131-3 **ST 语言** ② I/O 点数够 ③ 有以太网口 |
| 淘汰 | 信捷 XC3 主打梯形图、ST 支持弱 → **硬约束不满足，出局（哪怕最便宜）** |
| 合格候选 | 汇川、施耐德 TM241、西门子 S7-1200 |
| 软指标排序 | 西门子最贵；施耐德要回 Machine Expert（授权到期）；汇川 = CODESYS 内核 + 国产价 → **胜出** |

**核心教训**：信捷是"最便宜"但不是"性价比最高"，因为它过不了及格线（不兼容现有 ST 代码）。被低价吸引、忽略硬约束，是选型第一大坑。

**关键依据——CODESYS 内核**：本项目代码是 CODESYS V3.5 写的 ST。汇川 InoProShop 基于 CODESYS 内核，ST 代码（FB_Pusher 状态机、FB_Sorter、Modbus TCP 从站）可直接迁移，几乎零重写；信捷 XDPPro 非 CODESYS，代码要推倒重写成梯形图。省下的硬件钱，远不够填代码重写的时间成本。

## 三、颜色传感器选型（为什么不是普通光电）

| 步骤 | 内容 |
|------|------|
| 需求 | 分辨红/蓝/绿三色，输出分类结果 |
| 硬约束 | 必须能**区分颜色**——普通光电只能判断"有/无物体"，分不出颜色 |
| 淘汰 | 普通漫反射光电 → 过不了线 |
| 合格候选 | 颜色传感器（欧姆龙 E3ZG-V）或色标传感器（松下 LX-111） |
| 软指标 | 能否直接输出 1/2/3 数字（对上程序 iColorCode）、示教难度、价格 |

**为什么选"能分类输出多色"的型号**：程序里 `iColorCode : INT`（1=红/2=蓝/3=绿）期望传感器直接把颜色变成数字。欧姆龙 E3ZG-V 内部示教存下多色后直接输出分类结果，正好对上；若选只能识别单色的色标传感器，则需要 3 路开关量让 PLC 自己编码，增加接线和代码复杂度。

## 四、气缸选型（为什么双作用 + 二位五通阀）

| 步骤 | 内容 |
|------|------|
| 需求 | 推杆伸出、保持、再收回 |
| 硬约束 | 必须**双作用**——两个方向都要能主动动作 |
| 淘汰 | 单作用气缸（弹簧复位）做不到"伸出保持 2 秒"的稳定 |
| 对应阀门 | 双作用气缸 → 配**二位五通**电磁阀（两气口分别控制伸/缩）；单作用才配二位三通 |
| 软指标 | 缸径（推力）、行程（推多远）、品牌（亚德客国产性价比） |

**程序对应的物理逻辑**：FB_Pusher 状态机是"待机→伸出 2 秒→回位 1 秒"，伸出和回位都是主动动作，所以气缸必须双作用、阀必须二位五通。缸径 20~25mm 对轻载小工件足够。

## 五、选型的隐性成本（软指标排序不能只看标价）

| 隐性成本 | 说明 |
|----------|------|
| 代码迁移成本 | 汇川贵几百，但 ST 代码直接搬；信捷便宜，但重写代码花的时间远超差价 |
| 生态/售后 | 国产响应快、软件免费；进口要授权费 |
| 兼容性 | 新 PLC 与仿真器、Modbus 从站配置能否对上 |

## 六、一句话总结

> 先问"它必须做到什么"（定硬约束，一票否决），再问"合格品里哪个总成本最低"（软指标排序）。性价比是第二步，不是第一步。

选型的真正价值：**知道为什么，比记住型号重要得多。** 面试/答辩被问"为什么选这个 PLC/气缸"时，能按上面的逻辑讲清依据，而不是只背型号。
