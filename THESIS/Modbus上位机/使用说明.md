# Modbus 上位机工具 —— 使用说明

> 传送带分拣控制系统 · Modbus TCP 上位机演示
> 用于验证「上位机主站（Python）读 PLC 从站数据」的完整链路

---

## 一、这是什么

毕业设计里，PLC（CODESYS）负责分拣控制，上位机（这台电脑上的普通程序）通过 **Modbus TCP** 协议读取 PLC 的数据，显示成监控面板。

本文件夹是**上位机部分的完整工具**，包含：

| 文件 | 作用 |
|------|------|
| `启动模拟从站.bat`（原名"启动从站.bat"） | 双击 = 清端口 + 启动**模拟从站（测试用）** |
| `启动主站.bat` | 双击 = 启动上位机主站（读 PLC 数据） |
| `modbus_slave_simulator.py` | 模拟从站主体（Python，测试用） |
| `modbus_master.py` | 上位机主站主体（Python） |
| `使用说明.md` | 本文档 |

> ⚠️ 注意：「启动从站」启动的只是**模拟从站**（一段 Python 假数据），不是真 PLC，仅用于测试主站能不能正常读数据。要读真 PLC，见下方「五、对接真实 PLC」。

**两个角色：**

- **从站（Server）= PLC**：在一线接传感器/气缸，负责控制，被动等上位机来问。
- **主站（Client）= 上位机**：主动发请求，读取 PLC 数据做监控显示。

## 二、环境要求

- Windows 10/11
- Python 3.14（已装）
- pymodbus 3.15.0（已装到 Python 3.14）

**检查是否装好：**

```powershell
python -c "import pymodbus; print(pymodbus.__version__)"
```

看到 `3.15.0` 即正常。

## 三、快速开始（3 步）

### 第 1 步：启动模拟从站（测试用）

双击 **`启动从站.bat`**

会看到：

```
模拟从站已启动：127.0.0.1:502（测试用）
当前模拟数据：总数=16 红=4 蓝=6 绿=6
```

**这个窗口不要关**，它就相当于一台正在运行的 PLC（假数据）。

### 第 2 步：启动上位机主站

再双击 **`启动主站.bat`**

会看到监控面板：

```
==========================================
     传送带分拣监控（上位机主站）
==========================================
  分拣总数 : 16
  红色计数 : 4
  蓝色计数 : 6
  绿色计数 : 6
==========================================
```

### 第 3 步：退出

在两个窗口里分别按 **`Ctrl+C`**，或直接关窗口。

## 四、改模拟数据（验证用）

编辑 **`modbus_slave_simulator.py`**，找到顶部这一行：

```python
# ============ 在这里改模拟数据 ============
# 顺序：[分拣总数, 红色计数, 蓝色计数, 绿色计数]
REGISTERS = [16, 4, 6, 6]
# ==========================================
```

改完数字 → 保存 → 双击 `启动从站.bat` 重启（它会自动先清掉旧进程）→ 再看主站窗口，数据就变了。

> ⚠️ 常见坑：改了数据但主站显示没变，多半是**旧的从站进程还占着 502 端口**。
> 解决办法：直接双击 `启动从站.bat`（它内部会先杀旧进程），或手动执行：
> ```powershell
> Get-NetTCPConnection -LocalPort 502 | Select-Object -ExpandProperty OwningProcess | ForEach-Object { Stop-Process -Id $_ -Force }
> ```

## 五、对接真实 PLC（CODESYS）

现在跑的是「模拟从站」验证链路。接真实 PLC（CODESYS 仿真器）时：

1. CODESYS 设备树：`Device` 下加 **Ethernet** 适配器 → 在 Ethernet 下加 **ModbusTCP Server Device**（通用 TCP 服务器，无 Unit ID）
2. General 标签：**Port = 502**、**Input Registers = 4**（计数是 PLC 输出→主站读，放输入寄存器）
3. I/O Mapping 标签：把 4 个变量绑到输入寄存器：
   - 偏移0 → `GVL.wCountTotal`
   - 偏移1 → `GVL.wCountRed`
   - 偏移2 → `GVL.wCountBlue`
   - 偏移3 → `GVL.wCountGreen`
4. F5 启动仿真器（本机 `localhost:502` 开从站）
5. 直接双击 **`启动主站.bat`** —— 读到的就是 PLC 的真实计数

**寄存器映射（对应 thesis 需求文档）：**

| 寄存器 | 偏移 | 变量 | 含义 |
|--------|------|------|------|
| 30001 | 0 | wCountTotal | 分拣总数 |
| 30002 | 1 | wCountRed | 红色计数 |
| 30003 | 2 | wCountBlue | 蓝色计数 |
| 30004 | 3 | wCountGreen | 绿色计数 |

## 六、常见问题（FAQ）

**Q1：双击 `.bat` 闪一下就没了？**
先看主站窗口提示的错误信息。常见原因：Python 没装、pymodbus 没装、502 被占用。

**Q2：主站显示「连接失败」？**
按顺序检查：
1. 从站窗口是否还开着（模拟器有没有在跑）
2. 502 端口是否被别的程序占用

**Q3：改了 REGISTERS 但主站没变？**
旧从站进程没退干净，重新双击 `启动从站.bat` 即可。

**Q4：提示 `pymodbus` 找不到？**
终端里的 `python` 指向了别的版本。用 `py -3.14` 前缀运行，或确认 pymodbus 装在 3.14 上：
```powershell
py -3.14 -m pip install pymodbus
```

## 七、协议细节（技术备忘）

- 协议：Modbus TCP
- 功能码：04（Read Input Registers，读输入寄存器）
- 地址：127.0.0.1 : 502
- 读取：地址 0 起，连续 4 个寄存器

pymodbus 3.15 注意（新版 API 变更）：
- `ModbusDeviceContext`（旧名 `ModbusSlaveContext`）
- `ModbusServerContext(devices={1: store}, single=False)`
- 读取参数 `device_id=`（旧名 `slave=`）
