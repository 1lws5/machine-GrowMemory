传送带分拣控制系统 · HMI 演示

基于 CODESYS V3.5 + CODESYS Control Win V3 x64 仿真器，WebVisu 浏览器可视化。

① 主控页 VisuMain

启动 / 停止按钮、运行灯、报警灯、传送带动画、页面跳转。

② 分拣监控页 VisuMonitor

红 / 蓝 / 绿计数、总计数、当前颜色代码、推杆状态灯、计数复位。

③ 报警页 VisuAlarm

报警指示灯、报警文字提示、报警复位。

④ 操作演示视频

完整操作流程：启动 → 皮带运行 → 设颜色 → 触发到位 → 推杆分拣 → 计数 +1 → 报警复位。

💡 本页面为静态 HTML，图片和视频均本地引用，双击即可离线浏览全部内容，作为 GitHub 在线渲染之外的「二次保险展示」。若在 GitHub 网页上图片加载不全，直接下载本目录到本地打开本文件即可完整观看。
