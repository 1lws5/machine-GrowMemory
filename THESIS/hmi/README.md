# HMI 界面展示

## ① 主控页 VisuMain

![主控页](visu_main.png)

启动 / 停止按钮、运行灯、报警灯、传送带动画、页面跳转。

![报警页](visu_alarm.png)

报警指示灯、报警文字提示、报警复位。
